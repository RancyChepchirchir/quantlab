# Changelog

All notable changes to QuantLab will be documented in this file.

## [1.0.0]

### Added

- FastAPI quantitative backend
- Next.js Volatility Lab frontend
- Black–Scholes European option pricing
- CRR American option pricing
- European and American implied-volatility inversion
- Volatility smile analysis
- ATM volatility term structure
- Volatility skew diagnostics
- European put–call parity reference diagnostics
- Black–Scholes versus American IV comparison
- Raw SVI smile calibration
- SVI parameter diagnostics
- Butterfly warning diagnostics
- Cross-maturity calendar-arbitrage diagnostics
- IDW volatility-surface interpolation
- Massive market-data integration
- Alpha Vantage market-data integration
- Mock market-data provider
- Representative expiry selection
- Near-ATM matched call/put selection
- Service-level option-chain caching
- Provider failure cooldowns
- Structured provider error handling
- Market-data freshness and cache metadata in the frontend
- Backend unit and integration tests
- Frontend lint and production-build validation
- GitHub Actions CI
- Railway backend deployment
- Vercel frontend deployment
- Production smoke tests
- Release validation tooling
- Environment templates and dependency audit scripts

### Notes

QuantLab v1.0.0 establishes the stable research platform for derivatives pricing and volatility-surface analysis.

The project is intended for research and education rather than production trading or investment decision-making.
